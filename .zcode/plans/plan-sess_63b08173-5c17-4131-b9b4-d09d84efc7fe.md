# DrawPad — iPad 手绘 / Mac 实时显示画板

全新原生 Apple 平台项目（目录当前为空），一个 Xcode 工程两个 target + 共享核心代码，局域网（同 Sidecar 无线机制）连接。

## 技术选型

- **原生 Swift + SwiftUI + PencilKit**（唯一能做好 Apple Pencil 低延迟/压感/防误触的方案）
- **连接**：Network.framework TCP + Bonjour（`_drawpad._tcp.`）自动发现，Mac 作服务端持有全部数据（source of truth），iPad 作画布客户端。同一 WiFi 即可；USB 线直连（usbmux 隧道）和 PIN 配对放二期
- **最低系统**：macOS 14 / iPadOS 17
- **工程生成**：XcodeGen（`project.yml` → DrawPad.xcodeproj），共享 `Core/` 源码直接编入两个 target（不引入 SPM 包，减少复杂度）

## 目录结构

```
drawipad/
├── project.yml            # XcodeGen 配置（DrawPadMac / DrawPadPad 两个 target）
├── Core/                  # 两端共享：数据模型、同步协议、网络层
│   ├── Models/            # Folder、PageMeta、Library（Codable）
│   ├── Messages/          # 协议消息定义 + 4 字节长度前缀帧编解码
│   └── Network/           # Bonjour 广播/浏览、服务端/客户端连接封装、重连
├── MacApp/                # macOS 端：项目管理 UI、只读实时画布、持久化、PNG 导出
└── PadApp/                # iPadOS 端：连接页、PencilKit 画布、工具条、页面操作
```

## 核心设计

### 数据模型与存储（Mac 端持久化）
- `Folder`（文件夹/项目，含有序 pageIDs）→ `PageMeta`（名称、更新时间、strokeCount）
- 存储：`Application Support/DrawPad/library.json` + `pages/<uuid>.drawing`（`PKDrawing.dataRepresentation()` 原生二进制），笔画提交后防抖自动保存

### 同步协议（TCP 长连接，长度前缀帧）
- 控制消息 JSON：hello/accept、projectList、openPage(整页 drawing 数据)、pageCreate/pageDelete/pageSwitch、projectSelect、fullPageResync、断线重连后自动重新拉取
- 实时点流：紧凑二进制编码（x/y/force/altitude/azimuth/t，约 30ms 一批）
- 连接流程：iPad 浏览到 Mac → 连接 → **Mac 弹窗确认接受**（防陌生设备）→ 下发项目树 + 最近页面

### 实时绘制同步（完全实时的实现路径）
1. **进行中**：自定义 `UIGestureRecognizer` 观察者挂在 PKCanvasView 上（`cancelsTouchesInView=false`、永不进入 recognized 状态，不干扰 PencilKit），从 coalesced touches 采集压感点流式发送 → Mac 端叠加层画平滑预览线（按压力变宽度）
2. **抬笔提交**：`canvasViewDidEndUsingStroke` 取真实 PKStroke（PKDrawing 包装编码）→ Mac 替换预览线为真实墨迹 + 自动保存
3. **一致性兜底**：`canvasViewDrawingDidChange` 防抖比对 strokeCount，检测到撤销/橡皮/删减 → 整页重传，保证两端最终一致

### Mac 端 UI（macOS 14+）
- NavigationSplitView：侧边栏文件夹/页面列表（缩略图、新建/删除/重命名、右键菜单）+ 主区只读实时画布（PKCanvasView 只读显示）
- 工具栏：新建文件夹/页面、导出 PNG、连接状态指示；iPad 请求连接时弹确认框

### iPad 端 UI（iPadOS 17+）
- 连接页：自动扫描同网 Mac，点击连接等待确认
- 画布页：全屏 PKCanvasView + PKToolPicker（笔/橡皮/颜色/粗细）、撤销重做；顶部栏：项目切换、页面指示器（‹ 3/8 ›）、新建页、删除当前页（二次确认）、连接/重连状态
- Info.plist 必需：`NSLocalNetworkUsageDescription` + `NSBonjourServices`（否则 Bonjour 静默失败）

## 实施步骤（每步可编译验证）

1. **脚手架**：检查/安装 xcodegen → project.yml + Core 模型/协议/网络层 → 两 target 编译通过
2. **Mac 独立可用**：持久化 + 文件夹/页面管理 UI + 缩略图 + 导出 PNG（未连接即可单机使用）
3. **连接链路**：Bonjour 广播/浏览 + 配对确认 + 项目树/页面下发
4. **笔画同步**：先做抬笔提交路径（含自动保存、缩略图刷新），再加实时预览点流
5. **页面操作与鲁棒性**：iPad 端翻页/新建/删除/切项目、undo 整页重传、断线自动重连
6. **收尾**：空状态/错误提示、README（Mac 直接运行；iPad 真机需 Xcode 里选签名 Team 后 Cmd+R，免费 Apple ID 可用但 7 天需重签）

## 风险与对策
- GR 观察者如干扰 PencilKit 输入 → 降级为"抬笔提交"路径（架构已兼容，预览线独立成层）
- macOS PKCanvasView 只读显示的输入屏蔽细节实现时验证（透明遮挡层兜底）

## 二期候选（不在本次范围）
USB 线直连（usbmux/peertalk 隧道）、PIN 配对、多 iPad 同时连接、iCloud 同步、自定义笔刷引擎
